FLASHBOX — VIRTUAL PHOTO STUDIO
================================
Versi redesign total dari tema sebelumnya.

- Tema editorial / brutalist modern
- Font Bebas Neue + Space Grotesk
- Logo FLASHBOX custom
- Palet cream / black / orange
- Webcam, switch camera, countdown, retake
- 2 frame style
- Save PNG
- Photo strip

Buka index.html di Chrome/Edge. Jika kamera tidak aktif saat file dibuka langsung,
jalankan: python -m http.server 8000
lalu buka http://localhost:8000
